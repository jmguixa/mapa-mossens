# Mapa · Qui és fora

Mapa (Leaflet + OpenStreetMap) que s’incrusta a la pàgina «Qui està lliure» del doc «Mossens 26-27 · Oficina».
Les dades arriben només dins el hash de la URL (#d=…&p=…) i no es guarden enlloc.

Format de cada registre: `casa|lat|lon|inicials|nom|activitat|dates|ctr`, separats per `;`.
